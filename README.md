# 📚 Technical Writing — Learning Portfolio

### Technical Writing Laboratory | MNIT Jaipur

> **Write clearly. Document effectively. Collaborate confidently**

This repository brings together my Technical Writing coursework,
covering document preparation, presentations, source-code documentation,
collaborative writing, and version control.

The notes are organised around classroom lectures and laboratory assignments,
with explanations, command references, and practical examples.

## 🎯 Learning Objectives

- Prepare structured technical documents using LaTeX.
- Create academic presentations using Beamer.
- Document source code using Doxygen.
- Use Google Docs for collaborative technical writing.
- Track and manage changes using Git.
- Publish and organise work using GitHub.
- Explain and demonstrate the commands covered in class.
